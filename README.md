Real Estate Data Cleaning & Transformation Project

Project Overview

This project focuses on cleaning and transforming a messy real estate dataset using Microsoft Excel. The raw data contained multiple quality issues that needed to be resolved before it could be used for analysis, reporting, or dashb…
Requirement

Clean and transform the messy real estate dataset by addressing the following issues: duplicate records, missing values, inconsistent formatting, spelling errors, and mixed date formats. The goal was to use Excel functions, data cleaning techniques, and data validation to create an analysis-ready dataset suitable for reporting and dashboard creation.

Tools Used

Microsoft Excel (Advanced Functions, Data Validation, Conditional Formatting, PivotTables, Dashboard)

Data Cleaning Steps Performed

	1.	Removed Duplicate Records - Used Excel's Remove Duplicates feature to identify and eliminate duplicate rows.
	2.	Handled Missing Values - Identified blank cells using COUNTBLANK and filters, then filled or flagged them based on context.
	3.	Fixed Inconsistent Formatting - Standardized text case using UPPER, LOWER, and PROPER functions, removed extra spaces using TRIM.
	4.	Corrected Spelling Errors - Used Excel's built-in Spell Check and Find & Replace for recurring inconsistent entries.
	5.	Standardized Mixed Date Formats - Converted all date entries into a single consistent format using DATEVALUE and TEXT functions.
	6.	Applied Data Validation - Set up dropdown lists and validation rules to prevent future data entry errors.
